## Проект: Тестирование личного кабинета для учителей Skyeng 

▶️**Описание:**

Проводилось тестирование нового функционала для преподавателей платформы Skyeng — модуля «Личные события». Этот инструмент позволяет учителям добавлять в свое расписание персональные встречи и задачи, не привязанные к конкретным ученикам школы.

▶️**Цель проекта:**
Комплексная проверка новой фичи для принятия решения о готовности продукта к релизу.

[Ссылка на проект](https://github.com)

▶️**Выполненные работы:**
1. Проведен детальный анализ требований к новому функционалу.
2. Разработан комплект тестовой документации: чек-листы и тест-кейсы.
3. Выполнены следующие виды тестирования:
   * **Смоук-тестирование** (Smoke testing);
   * **Функциональное тестирование** основных сценариев;
   * **Регрессионное тестирование** после исправления дефектов;
   * **Приемочное тестирование** (UAT).
4. Зафиксированы найденные дефекты (оформлены баг-репорты).
5. Подготовлен финальный отчет о результатах тестирования с рекомендациями по релизу.

▶️**Какие инструменты были применены:**

- Miro для создания декомпозиции новой функциональности
- TestIT для подготовки тест-кейсов и чек-листов
- Yonote для ведения тест-плана и отчета
- Ёжка для фиксирования найденных дефектов
